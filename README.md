# SAWL Reading Blog · 86쪽 4번

무료 도구 기반 GitHub Pages용 영어 독해 학습 사이트입니다.

## 구성
- `index.html`: 사이트 본문
- `style.css`: 디자인
- `app.js`: 단계 잠금, keyword 확인, 저장 기능
- `assets/logo-horizontal.jpg`: 수원외고 가로형 시그니처 로고
- `assets/passage-page86-no4.png`: 지문 필기용 이미지
- `custom_gpt_prompt.txt`: Custom GPT Instructions용 프롬프트
- `.nojekyll`: GitHub Pages 배포 보조 파일

## 사용 방식
1. GitHub repository 최상단에 모든 파일을 업로드합니다.
2. Settings → Pages → Deploy from a branch → main / root를 선택합니다.
3. 생성된 GitHub Pages 링크를 Google Classroom에 공유합니다.
